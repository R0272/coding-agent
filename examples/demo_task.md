# 演示任务建议（用于录制 2 分钟以内的视频）

录屏时建议使用下面这类"有明确验证标准"的任务，方便在 2 分钟内既展示过程又展示结果：

```bash
python run.py -t "在当前工作目录下实现一个 calculator.py，
包含 add/sub/mul/div 四个函数，div 遇到除以 0 要抛出 ValueError；
再写一个 test_calculator.py 用标准库 unittest 覆盖这四个函数（含除零场景），
最后运行测试，确保全部通过，把最终测试输出展示出来。"
```

建议演示节奏（共约 2 分钟）：
1. 0:00-0:15 展示 `.env` 已配置（打码密钥）、`python run.py -t "..."` 敲下任务；
2. 0:15-1:20 快进播放智能体的完整过程：可以看到它依次调用 `list_dir`（先看现状）→
   `write_file` 写 calculator.py → `write_file` 写测试文件 → `run_bash` 运行
   `python -m unittest` → 根据测试结果决定是否需要用 `edit_file` 修正 bug；
3. 1:20-2:00 展示最终测试全部通过的输出，并口头/字幕简要说明实现的关键点
   （原生 tool calling 解析、路径沙箱、错误重试、上下文压缩等）。

也可以换成任意你自己准备的、更能体现"多轮修正"能力的任务，
例如故意让第一版代码里留一个小 bug，展示智能体如何根据 run_bash 的报错自己发现并修复。
